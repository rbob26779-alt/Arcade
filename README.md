# Arcade Hub 3.0

20 playable browser games, local username/password accounts, global online leaderboard, and live two-player party matches for Tic-Tac-Toe and Connect Four.

## Run locally
Install Node.js 18+ and run `npm install`, then `npm start`. Visit http://localhost:3000.

## Publish a public URL
Push these files to a GitHub repository and deploy as a **Node web service** on a hosting provider such as Render. Build command: `npm install`. Start command: `npm start`. Set `SESSION_SECRET` to a long random secret and `NODE_ENV=production`. A public HTTPS URL is assigned by your host; it cannot be generated by this ZIP alone. Share that URL. Party invites are generated from your actual deployed URL.

**Important hosting limits:** This starter uses `data.json` for accounts/stats and in-memory sessions and rooms. On free hosts with ephemeral disks, accounts/stats can disappear on redeploy/restart; use a persistent disk/database and session store before treating it as a permanent public service. It assumes one server instance. Free hosts may sleep, causing party disconnects. There is no email verification, password reset, moderation system, or abuse reporting yet. Do not reuse important passwords. The 18 solo games run in the browser; only Tic-Tac-Toe and Connect Four currently support real online multiplayer. Online match results are server-validated; solo results do not affect the global leaderboard.

## Files
- `server.js`: Express API, accounts, leaderboard, Socket.IO parties and server-authoritative match rules.
- `public/`: browser interface and 20 games.
